# FitFlow AI Service

This directory contains the AI and recommendation service for the FitFlow redesign.

## Technology

- FastAPI
- Python

## Responsibilities

The AI service handles:

- Personalized workout recommendations
- Recommendation scoring
- AI-assisted fitness suggestions
- Nutrition-related suggestions
- Model inference
- Communication with the main NestJS backend

The AI service is separated from the main backend so that machine learning features can be developed and scaled independently.
